Car Brand Classification System Using CNN
=========================================

Project Folder
==============
- app.py
- train_model.py
- prepare_dataset.py
- requirements.txt
- car_brand_classifier.keras
- dataset/
- raw_dataset/
- test_images/
- PROJECT_REPORT.md

Command
=======
1. Install the required packages:
	pip install -r requirements.txt
2. Prepare the dataset split:
	python prepare_dataset.py
3. Train and evaluate the CNN:
	python train_model.py
4. Run the Streamlit application:
	streamlit run app.py
