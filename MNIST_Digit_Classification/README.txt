MNIST HANDWRITTEN DIGIT CLASSIFICATION
======================================
This Project uses:
-Python
-TensorFlow / Keras
-MNIST dataset
-Neural Network
-Streamlit

PROJECT FILES
=============
train_model.py
app.py
requirements

COMMANDS
==========
1. Install Packages:
        pip install -r requirements.txt
2. Train the model:
        python train_model.python
3. Run Streamlit :
        streamlit run app.py
