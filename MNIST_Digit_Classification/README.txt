MNIST HANDWRITTEN DIGIT CLASSIFICATION
=======================================
This project uses:
-Python
-TensorFlow / Keras
-MNIST dataset
-Neural Network
-streamlit

PROJECT FILES
==============
train_model.py
app.py
requirements

COMMANDS
=========
1. Install packages:
	pip install -r requirements.txt
2. Train the model:
	python train_model.py
3. Run Streamlit:
	streamlit run app.py
